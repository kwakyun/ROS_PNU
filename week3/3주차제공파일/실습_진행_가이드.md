## 1단계: 워크스페이스 준비 및 패키지 빌드

이미 구현이 완료된 `week03_ros2_jetson` 패키지를 워크스페이스로 이동하고 빌드합니다.

### 1-1. 워크스페이스 디렉토리 생성 및 패키지 복사
```bash
# 1. 3주차 작업 디렉토리 생성 및 이동
mkdir -p ~/week3
cd ~/week3

# 2. 제공된 week03_ros2_jetson 패키지 배치
# 방법 A: 폴더 직접 복사 (USB 또는 SCP)
# 구조 확인: ~/week3/week03_ros2_jetson/package.xml 형태가 되어야 함
ls -la ~/week3/week03_ros2_jetson

# 방법 B: 제공된 압축 파일(week03_ros2_jetson.zip)을 사용할 경우
unzip week03_ros2_jetson.zip -d ~/week3/
```

### 1-2. 패키지 빌드 (`colcon build`)
```bash
cd ~/week3
source ~/ros2_base/install/setup.bash

# week03_ros2_jetson 패키지 빌드
colcon build --symlink-install --packages-select week03_ros2_jetson

# 빌드 산출물 환경 로드
source install/setup.bash
```

### 1-3. 실행 파일 등록 확인
```bash
ros2 pkg executables week03_ros2_jetson
```
**정상 출력 결과 (4개 등록 확인):**
```text
week03_ros2_jetson joint_monitor.launch.py (launch)
week03_ros2_jetson bringup.launch.py (launch)
week03_ros2_jetson joint_state_publisher
week03_ros2_jetson joint_state_listener
week03_ros2_jetson joint_state_service_server
week03_ros2_jetson joint_state_service_client
```

## 2단계: [실습 1] Topic 발행 및 구독 확인

실제 로봇 암의 6개 관절 각도를 읽어 `/joint_states` 토픽으로 20Hz 주기로 발행하고 수신하는 단계입니다.

### 2-1. Launch 실행 (터미널 1)
```bash
source ~/ros2_base/install/setup.bash
source ~/week3/install/setup.bash

ros2 launch week03_ros2_jetson joint_monitor.launch.py
```
> **확인 사항**:
> - `joint_state_publisher`와 `joint_state_listener`가 동시 실행됨
> - 터미널에 6개 관절 각도(rad 및 deg)가 실시간으로 출력되는지 확인

### 2-2. Topic 상태 검증 (터미널 2)
새 터미널을 열고 아래 명령어로 Topic을 점검합니다:

```bash
source ~/ros2_base/install/setup.bash
source ~/week3/install/setup.bash

# 1. 실행 중인 노드 목록 확인
ros2 node list
# -> /joint_state_publisher, /joint_state_listener 표시 확인

# 2. 토픽 메시지 인터페이스 타입 확인
ros2 topic type /joint_states
# -> sensor_msgs/msg/JointState 확인

# 3. 토픽 발행 주기 확인 (joints.yaml 설정값 약 20Hz)
ros2 topic hz /joint_states
# -> average rate: 20.0xx Hz 확인

# 4. 토픽 메시지 1회 내용 출력
ros2 topic echo --once /joint_states
# -> 6개 관절 이름(name)과 각도(position) 배열 확인
```

> 확인이 끝나면 터미널 1에서 `Ctrl + C`를 눌러 프로그램을 종료합니다.

## 3단계: [실습 2] Service 통신 및 Bringup 실행

`joint_state_publisher`와 `joint_state_service_server`를 실행하고, 클라이언트(Python & CLI)에서 1회 요청하여 최신 관절값을 수신하는 단계입니다.

### 3-1. Bringup Launch 실행 (터미널 1)
```bash
source ~/ros2_base/install/setup.bash
source ~/week3/install/setup.bash

ros2 launch week03_ros2_jetson bringup.launch.py
```
> **확인 사항**:
> - `joint_state_publisher`와 `joint_state_service_server` 노드가 정상 기동됨

### 3-2. Python Service Client 호출 (터미널 2)
```bash
source ~/ros2_base/install/setup.bash
source ~/week3/install/setup.bash

ros2 run week03_ros2_jetson joint_state_service_client
```
**정상 출력 결과:**
```text
[Service response]
shoulder_pan=+0.000 rad (+0.0 deg) | shoulder_lift=+0.000 rad (+0.0 deg) | elbow_flex=+0.000 rad (+0.0 deg) | wrist_flex=+0.000 rad (+0.0 deg) | wrist_roll=+0.000 rad (+0.0 deg) | gripper=+0.000 rad (+0.0 deg)
```

### 3-3. ROS 2 CLI를 통한 Service 검증 (터미널 3)
```bash
source ~/ros2_base/install/setup.bash
source ~/week3/install/setup.bash

# 1. 서비스 목록 확인
ros2 service list
# -> /get_joint_state 항목 확인

# 2. 서비스 인터페이스 타입 확인
ros2 service type /get_joint_state
# -> std_srvs/srv/Trigger 확인

# 3. CLI로 직접 서비스 호출
ros2 service call /get_joint_state std_srvs/srv/Trigger "{}"
```
**정상 출력 결과:**
```text
requester: making request: std_srvs.srv.Trigger_Request()

response:
std_srvs.srv.Trigger_Response(success=True, message='shoulder_pan=+0.000 rad (+0.0 deg) | shoulder_lift=+0.000 rad (+0.0 deg) | elbow_flex=+0.000 rad (+0.0 deg) | wrist_flex=+0.000 rad (+0.0 deg) | wrist_roll=+0.000 rad (+0.0 deg) | gripper=+0.000 rad (+0.0 deg)')
```

## 4단계: 조교 최종 검사 체크리스트

조교님께 다음 4가지 핵심 항목을 순서대로 시연하고 확인을 받습니다.

| 검사 항목 | 확인 명령어 | 정상 기준 |
|---|---|---|
| **1. 노드 실행 상태** | `ros2 node list` (Bringup 실행 중) | `/joint_state_publisher`, `/joint_state_service_server` 존재 |
| **2. Topic 발행 주기 및 포맷** | `ros2 topic hz /joint_states`<br>`ros2 topic echo --once /joint_states` | 약 20 Hz 발행<br>6개 관절의 name과 position 배열 일치 |
| **3. Service 인터페이스 타입** | `ros2 service type /get_joint_state` | `std_srvs/srv/Trigger` |
| **4. 최신값 응답 확인** | `ros2 run week03_ros2_jetson joint_state_service_client`<br>`ros2 service call /get_joint_state std_srvs/srv/Trigger "{}"` | `success=True` 및 최신 6개 관절 각도값 반환 |

## 5단계: 실습 종료 및 기자재 정리

실습이 완료된 후 아래 규정에 맞춰 감점이 없도록 기자재를 정리합니다.

1. **실행 중인 모든 프로세스 종료**: 각 터미널에서 `Ctrl + C` 입력
2. **실습 기자재 정리 매뉴얼 준수**:
   - LAN 케이블 (2개)
   - 파워 케이블 (2개)
   - HDMI 케이블 (1개)
   - USB to Ethernet 어댑터 (1개)
   - 모니터 파워 케이블 (1개)
3. **주의 사항**:
   - 모니터 파워 케이블을 제외한 모든 부품은 **원래의 개별 비닐백**에 넣은 후 정리함
   - 작은 비닐이나 완충 박스를 임의로 버리지 말 것 (정리 상태 불량 시 조별 감점 대상)

## 💡 주요 트러블슈팅 및 팁

- **Q: `/dev/ttyACM0` 권한 오류 또는 파일 없음이 뜹니다.**
  - A: 로봇 암의 USB 케이블 연결을 다시 확인하고, 권한 문제가 발생하면 `sudo chmod 666 /dev/ttyACM0`을 실행합니다.
- **Q: `Duplicate package names not supported` 에러가 납니다.**
  - A: `3주차제공파일/source_code`와 `week03_ros2_jetson`의 패키지 이름이 중복되어 발생하는 오류입니다. 제공 파일 폴더를 제외하도록 `touch ~/week3/3주차제공파일/COLCON_IGNORE`를 실행한 후 다시 빌드하세요.
- **Q: `colcon build` 시 패키지를 찾지 못합니다.**
  - A: 반드시 `~/week3` 디렉토리 안에서 실행해야 하며, `~/week3/week03_ros2_jetson/package.xml`이 올바른 위치에 있는지 확인합니다.
- **Q: 새 터미널을 열었을 때 `ros2` 명령어가 실행되지 않거나 노드를 찾지 못합니다.**
  - A: 새 터미널마다 반드시 아래 두 줄을 먼저 실행해야 합니다:
    ```bash
    source ~/ros2_base/install/setup.bash
    source ~/week3/install/setup.bash
    ```
- **Q: `bringup.launch.py`와 `joint_monitor.launch.py`를 동시에 실행해도 되나요?**
  - A: **안 됩니다.** 시리얼 포트(`/dev/ttyACM0`)는 하나의 `joint_state_publisher` 프로세스만 독점하여 사용할 수 있으므로 하나를 종료한 후 다른 하나를 실행해야 합니다.
