# 학습 모델 저장 위치

이 폴더에는 실습에서 학습한 모델을 저장한다.
팀별 촬영 데이터로 학습한 모델은 포함하지 않는다.

실행 폴더 `~/week7`의 세 도구로 수집·학습을 수행하면 다음 파일을 생성한다.

- vision_pose_best.pt
- vision_pose_best.vision.json

두 파일의 클래스·tip 기준·영상 크기가 config/vision.yaml과 일치해야 한다.
모델을 생성하거나 교체한 뒤에는 패키지를 다시 빌드한다.
사전학습 yolo11n-pose.pt는 실행 폴더 `~/week7`의 최상위에 있으며 추론용 학습 모델과 다르다.
